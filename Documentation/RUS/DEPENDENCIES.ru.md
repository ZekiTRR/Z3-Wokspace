## Тулчейны

Сейчас поддерживаются и протестированы:

```text
Windows: MinGW-w64 GCC 13.1.0 (поставляется с Qt, E:/Qt/Tools/mingw1310_64)
Linux:   GCC, Clang (поддерживаются дизайном сборки; CI-матрица — позже)
```

**MSVC не является поддерживаемым компилятором.** Кодовая база и структура
CMake сохраняются переносимыми, чтобы позже добавить MSVC через
`cmake/CompilerWarnings.cmake` / `cmake/CompilerOptions.cmake` и отдельную
MSVC-совместимую установку Qt — без перепроектирования приложения.

## Примечания

- Z3 собирается как **статическая** библиотека
  (`Z3_BUILD_LIBZ3_SHARED=OFF`), поэтому деплой `z3.dll` не требуется.
- Официальные бинарники Z3 для Windows из релизов собраны MSVC и
  сознательно не используются.
- Qt никогда не скачивается и не устанавливается проектом; используется
  установка пользователя «как есть».
- Сгенерированные бинарные артефакты (`ThirdParty/Z3/install`, `build/`) не
  коммитятся.

## Стандарт C++

C++20, строгий (`CMAKE_CXX_STANDARD_REQUIRED ON`, без компиляторных
расширений). Возможности C++23+ избегаются ради совместимости с GCC
и Clang.
