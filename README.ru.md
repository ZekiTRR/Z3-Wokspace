Настольная рабочая среда в стиле IDE для **SMT-решателя
[Z3](https://github.com/Z3Prover/z3)**: описывайте переменные и ограничения
на небольшом предметно-ориентированном DSL, нажимайте `Solve` и изучайте
полученную модель — создано для reverse engineering, CTF, символьных
вычислений и повседневных экспериментов с ограничениями.

```dsl
var x: BitVec(32)

constraint ((x ^ 0x1337) + 10) == 0x4242
```

Нажмите `F5` → **SAT**, `x = 0x0000510f (20751)`.

## Возможности

**Редактирование задач**

- Собственный DSL: `Int`, `Real`, `Bool`, `String`, `BitVec(1..64)`
- Живая диагностика на каждое нажатие клавиши — синтаксические *и*
  типовые ошибки с позициями строка/столбец; задача хранит последнее
  валидное состояние, пока вы печатаете
- Подсветка синтаксиса DSL, моноширинный редактор, RE-ориентированные
  приоритеты (`x ^ 0x1337 == 0x4242` разбирается так, как вы ожидаете)

**Решение**

- Решение в один клик (`F5` / `Ctrl+Enter`) → `SAT` / `UNSAT` / `UNKNOWN`
- Асинхронное выполнение: интерфейс никогда не замирает; кооперативный
  `Stop` + таймаут на запуск (по умолчанию 5 с)
- Просмотр модели по всем объявленным переменным; значения BitVec в виде
  hex + десятичное; клик копирует значение
- Консольный журнал каждого шага, время решения, причина бэкенда при
  `UNKNOWN`

**Проекты и файлы**

- Формат проектов `.z3w` (JSON, версионированная схема, готовность к
  миграциям)
- Недавние проекты, индикатор несохранённых изменений, сохранение
  геометрии окна
- Экспорт отдельной задачи в переносимый **SMT-LIB2**, структурный **JSON**
  или человекочитаемый **TXT**-листинг
- Импорт SMT-LIB2 обратно в редактируемую задачу (подмножество экспортёра)

**Качество инженерии**

- Библиотека core без Qt; Z3 строго за границей адаптера
- Unit + интеграционные тесты парсера, проверки типов, решателя,
  сериализации (doctest + CTest); сборка без предупреждений
  (`-Wall -Wextra -Wpedantic`)
- CI-матрица: Linux GCC, Linux Clang, Windows MinGW GCC

## Быстрый старт (Windows, MinGW)

```powershell
scripts/bootstrap_z3.ps1   # однократно: локальная сборка pinned Z3 5.1.0
scripts/configure.ps1      # cmake-конфигурация в build/mingw-debug
scripts/build.ps1          # компиляция
scripts/test.ps1           # запуск тестов
scripts/run.ps1            # запуск приложения
```

В Linux используется `scripts/bootstrap_z3.sh` плюс обычный CMake. Полные
инструкции, детали тулчейнов и устранение неполадок:
[BUILD.ru.md](Documentation/RUS/BUILD.ru.md).

## Карта репозитория

```text
src/core/    domain, parser, solver (+ Z3 adapter), serialization — без Qt
src/gui/     viewmodels, models, рабочий поток, подсветка
src/app/     точка входа + QML-модуль
qml/         тёмная IDE-оболочка, панели
tests/       наборы doctest, зеркалирующие core/parser/solver/serialization
scripts/     bootstrap_z3 · configure · build · test · run
cmake/       политика предупреждений, зависимости, поиск Qt/Z3
```

## Вектор развития в будущем

MVP, описанный выше, завершён (9 фаз разработки). Дальнейшие шаги:

1. **Продвинутое решение** — unsat cores, цели оптимизации
   (maximize/minimize), push/pop, инкрементальное решение, assumptions
2. **Дополнительные бэкенды** — CVC5, Boolector за существующим интерфейсом
   `ISolver`; интерфейс опций решателя (таймаут, random seed)
3. **Структурированное редактирование задач** — визуальный режим
   переменных/ограничений рядом с текстовым редактором, инспекция дерева
   выражений
4. **Продуктивность редактора** — поиск/замена, переход к определению
   переменной, rename-рефакторинг по всем ограничениям
5. **Более глубокая диагностика** — панель статистики (conflicts,
   decisions), сравнение SMT-LIB2 видов бэкенда и переносимого экспорта
6. **Расширение платформенной истории** — подписанные установщики,
   упаковка деплоя, поддержка тулчейна MSVC за существующим слоем
   компиляторной политики

Долгосрочное видение: полноценная IDE для constraint solving и символьного
исполнения — где crackme, CTF-задачи и проблемы распределения регистров
решаются за секунды, а не вечера.
